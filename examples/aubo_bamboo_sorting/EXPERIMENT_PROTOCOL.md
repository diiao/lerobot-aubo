# 无序竹条分拣实验协议

## 1. 固定任务边界

第一版仅使用静止料台、统一规格竹条和固定收集区，不使用传送带，也不要求定向码放。目标场景为
5–10 根中等堆叠；在此前必须依次通过只读状态、仿真、无物低速、单根、交叉双根和小堆叠阶段门。

碰撞、安全限位越界或未处理的保护停止，任何一次发生都使当前阶段门失败。仿真通过只说明模型和
轨迹检查可用，不等于真机安全或抓取成功。

## 2. 结果定义

- `success`：竹条已由独立视觉/传感证据确认抓起，并安全释放到固定收集区。
- `failure`：有明确证据表明未抓起、掉落、误抓多根或任务未完成。
- `uncertain`：证据不足、相机断流或状态冲突；执行安全停止/回撤，不计作成功。

`ee.gripper_pos` 仅表示最后命令的 `0=张开/释放、100=闭合/夹持`，不能单独作为抓取成功证据。
每次抓取、失败或回撤后必须重新采集场景，禁止复用旧料堆计划。

## 3. 150 次上限分配

| 阶段 | 次数 | 是否进入性能统计 |
|---|---:|---|
| 低速工程验收 | 10 | 否 |
| Pilot：交叉双根 | 20 | 是 |
| Pilot：3–5 根稀疏 | 20 | 是 |
| Pilot：5–10 根中等堆叠 | 20 | 是 |
| 连续清空场景 | 20 个场景 | 单独报告 |
| 冻结后对照：几何法 | 20 | 是 |
| 冻结后对照：几何法+腕部视觉伺服 | 20 | 是 |
| 冻结后对照：ACT | 20 | 是 |

Pilot 后按场景分别报告 `成功数/总数` 和 Wilson 95% 置信区间，再冻结正式性能门槛。冻结后不得
使用同一批正式试验继续调参；若改动算法或阈值，应另开实验版本并重新评估。

## 4. 每次试验记录

至少保存：版本/提交、方法、场景层级、竹条数、随机化编号、原始 SceneFrame、点云质量报告、
可见段、所有候选及评分分解/拒绝原因、最终候选、状态机轨迹、结果分类、失败原因、视觉证据、
保护停止、人工干预和总周期时间。ACT 对照必须重新采集与新相机观察配置一致的数据并训练，不能
直接加载旧场景 checkpoint 后宣称公平对照。

## 5. 对照公平性

几何法、几何法加腕部视觉伺服、ACT 必须使用相同竹条规格、场景分布、夹爪、相机、起始位姿、
安全层和指标。正式试验顺序应随机化或交错安排，以降低光照、气压和设备温漂造成的顺序偏差。
